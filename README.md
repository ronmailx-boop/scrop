# Scrop – חיתוך תמונות מסריקה

אפליקציית PWA שעושה דבר אחד: סורקים כמה תמונות יחד על משטח סורק A4, ו-Scrop חותכת כל תמונה מתוך הסריקה ושומרת אותה כקובץ נפרד — **בלי שום פגיעה באיכות**.

- הכול רץ בדפדפן. אין שרת, אין חשבונות, אין אנליטיקס — הקבצים לא יוצאים מהמכשיר.
- עובדת גם אופליין (Service Worker), ואפשר לשתף אליה קובץ מתפריט השיתוף באנדרואיד.

## שימוש

1. **בחר קובץ** — PDF, ‏JPG או PNG (ב-PDF עם כמה עמודים יש בורר עמודים).
2. **+ הוסף חיתוך** — לכל תמונה מלבן משלה: גוררים להזזה, ידיות לשינוי גודל, צביטה לזום. אפשר להקליד מיקום וגודל מדויקים בפיקסלים או במ"מ.
3. אופציונלי, לכל חיתוך: **סיבוב והתאמות תמונה** — סיבוב ב-90° ושינוי בהירות, ניגודיות וחיות (רוויה), עם תצוגה מקדימה. "החל על כל החיתוכים" מעתיק את ההגדרות לכל התמונות.
4. בוחרים פורמט (אותו פורמט כמו המקור / JPG / PDF) ולוחצים **שמור הכל**.
5. שמירה כ-ZIP, שיתוף, או הורדה של כל קובץ בנפרד (`scrop_1`, `scrop_2`, …).

## איכות

- החיתוך נעשה תמיד על הפיקסלים המקוריים ברזולוציה מלאה, בלי הקטנה ובלי החלקה. הרזולוציה של כל חיתוך מוצגת במסך.
- PNG נשמר כ-PNG (ללא אובדן, זהה לפיקסל). JPG נשמר בקידוד יחיד באיכות 1.0; חיתוך של התמונה כולה מחזיר את הקובץ המקורי כמות שהוא.
- PDF מסורק (תמונה אחת לעמוד): התמונה המוטמעת נשלפת ברזולוציה המקורית שלה. PDF אחר מרונדר ב-300 DPI לפחות.
- פלט PDF: כל חיתוך הוא PDF נפרד בגודל עמוד זהה בדיוק לחיתוך, בלי שוליים, עם התמונה ברזולוציה מלאה (JPEG או PNG ללא אובדן).
- סיבוב ב-90° הוא העברת פיקסלים בלבד, בלי דגימה מחדש. בהירות/ניגודיות/חיות משנות את הפיקסלים (זו מטרתן), ומחושבות באותה נוסחה כמו מסנני CSS. חיתוך בלי התאמות נשמר בדיוק כמו קודם.
- ה-DPI של המקור נשמר בקבצי הפלט, כך שגודל ההדפסה נשמר.

## מבנה

```
public/            האפליקציה (זה מה שעולה ל-GitHub Pages)
  index.html, styles.css, app.js (ממשק), engine.js (טעינה/חיתוך/ייצוא)
  sw.js, manifest.webmanifest, icons/
  vendor/          pdf.js, pdf-lib, fflate — מקומיים, בלי CDN
  .well-known/assetlinks.json   תבנית ל-TWA (com.vplusstudio.scrop)
tests/             יצירת סריקת דוגמה ובדיקת E2E
```

## פיתוח

```sh
npm install
npm run serve          # http://localhost:8080
npm test               # דורש Playwright + Chromium
npm run vendor         # רענון הספריות ב-public/vendor מ-node_modules
```

הבדיקה יוצרת סריקת A4 ב-300 DPI עם 4 תמונות בגדלים שונים (PNG, ‏JPG, ושלושה סוגי PDF), מגדירה 4 חיתוכים, ובודקת שמידות כל קובץ פלט שוות בדיוק לחיתוך ושהתוכן תואם לקואורדינטות (ב-PNG — זהות פיקסל-לפיקסל).

בכל שחרור יש להעלות את `VERSION` ב-`public/sw.js` כדי שהמשתמשים יקבלו את הקבצים החדשים.

## פריסה

GitHub Actions מפרסם את `public/` ל-GitHub Pages בכל push ל-`main`.
הגדרה חד-פעמית: ‏Settings → Pages → Source: **GitHub Actions**.

## TWA (Google Play) בעתיד

ה-manifest מוכן (id, אייקונים רגילים ו-maskable, share target). `assetlinks.json` חייב לשבת בשורש הדומיין (`/.well-known/`), ולכן לפני בניית TWA צריך דומיין משלה (למשל `scrop.vplusstudio.app`) ולהחליף את טביעת האצבע של מפתח החתימה.
